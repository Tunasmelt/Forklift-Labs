# Adding real images

Drop your photos into `public/images/` using these exact filenames (referenced in `data/projects.js`):

- `letap.jpg` — Letap International (freight container)
- `copilot.jpg` — Invoicing Copilot (papers/invoices)
- `drifter.jpg` — Drifter (dark abstract lines)
- `graphify.jpg` — Graphify (sand-carved graph)
- `codelearn.jpg` — CodeLearn (product device)

Each is used both in the gallery card and its detail modal — no code changes needed, just add the files.
